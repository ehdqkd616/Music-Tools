# Studio 서버 관리 (GUI)

`docker compose` 스택을 버튼으로 시작/중지/재시작하고 실시간 로그를 보는 작은 Tkinter 앱.
표준 라이브러리만 쓰므로 추가 설치가 필요 없다 (Python + Docker Desktop만 있으면 됨).

## 실행

저장소 루트의 **`Studio 서버 관리.vbs`** 를 더블클릭 — 콘솔 창 없이 바로 GUI가 뜬다.

문제가 있어 콘솔 출력을 봐야 하면 `tools/server-manager/run-debug.bat` 을 실행한다.

## 화면 구성

- **전체 제어**: 전체 시작(`up -d`) / 전체 중지(`stop`, 컨테이너는 유지) / 이미지 빌드(`build`) /
  상태 새로고침 / 컨테이너 삭제(`down`, 확인 창 있음 — 볼륨/DB 데이터는 유지됨)
- **서비스 상태**: 각 서비스 상태를 5초마다 자동 새로고침. 행을 선택하면 오른쪽에
  개별 시작/중지/재시작/로그 보기 버튼이 활성화된다.
- **로그**: 상단 콤보박스로 "전체" 또는 특정 서비스 로그로 전환. `error`/`warning` 포함 줄은
  색으로 강조된다.

## 참고

- 이 창을 닫아도 도커 컨테이너는 계속 실행된다 (전체 중지 버튼을 눌러야 멈춘다) — 창은 관리
  도구일 뿐, 컨테이너 자체를 소유하지 않는다.
- Docker Desktop이 꺼져 있으면 상태/로그 조회가 실패하고 상단에 안내 메시지가 뜬다.
